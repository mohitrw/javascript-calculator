# JavaScript Calculator 🧮

A functional calculator built with HTML, CSS, and JavaScript. It features a clean neumorphic interface and supports basic arithmetic operations through an interactive keypad.

🚀 **Live Website:** [Try the Calculator](https://mohitrw.github.io/javascript-calculator/)

## ✨ Features

- ➕ **Basic Arithmetic** — Perform addition, subtraction, multiplication, and division.
- 🔢 **Interactive Keypad** — Enter numbers and operators using the on-screen buttons.
- 🧹 **Clear & Delete** — Clear the calculation or remove the last character.
- 🎨 **Neumorphic UI** — A modern interface with soft shadows and rounded buttons.
- ⚡ **Lightweight** — Built using standard web technologies.

## 🛠️ Built With

- **HTML5** — Calculator structure.
- **CSS3** — Layout, styling, and neumorphic effects.
- **JavaScript** — Calculator logic and button interactions.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR-REPOSITORY-URL
   ```

2. Open the project folder:

   ```bash
   cd javascript-calculator
   ```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
